# HoraCerta

Projeto desenvolvido para a disciplina de Desenvolvimento para Web.

## Sobre o projeto

O HoraCerta tem como foco principal acertar os horários e os agendamentos de eventos da escola, ajudando a organizar melhor a rotina escolar.

## Funcionalidades

- Ajuste de horários escolares
- Agendamento de eventos da escola
- Organização centralizada dos compromissos
